# Parallel AI QA starter kit

Prepared by Rox Valdina • v1.0 • November 13, 2026

These are general templates derived from one practitioner's workflow. Adapt them to your application and test them before release use. They are starting instructions and design aids, not executable coordination or authentication software.

## Start small

1. Read operating-rules.md and fill in your environment, access and approval boundaries.
2. Use data-pool.json or data-pool.csv to describe one representative scenario. Run the verification method and record its evidence before marking an entry verified. Read data-pool-guide.md for role dependencies, locks, leases and cleanup.
3. Follow authentication-recipe.md with two disposable browser sessions.
4. Run verification-exercises.md using the same chat nesting and permissions you normally use.
5. Log the times you intervene in intervention-log.csv. Expand only after reviewing the outcomes.

Files include editable examples. DEMO identifiers and example.invalid hosts are fictional. Keep actual credentials, saved authentication state, customer records and internal infrastructure out of public source and shared downloads. Record local references to protected state rather than token contents.

Adaptation prompts are in prompts/ and are also available in the case study. Replace bracketed values before use. A prompt cannot grant access, change platform policy, or guarantee that an agent follows instructions. Validate the resulting behavior.
